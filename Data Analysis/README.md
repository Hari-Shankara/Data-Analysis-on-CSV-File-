
# Task 5: Data Analysis on CSV Files

## Objective
Analyze sales data using Python and Pandas.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Files
- sales.csv - Sales dataset
- analysis.py - Python analysis program
- requirements.txt - Required libraries
- analyzed_sales.csv - Analyzed dataset
- revenue_by_product.png - Product chart
- revenue_by_category.png - Category chart
- revenue_by_region.png - Region chart

## Analysis Performed
1. Loaded CSV using Pandas.
2. Displayed the first five rows.
3. Checked dataset information and shape.
4. Calculated total sales revenue.
5. Grouped sales by product.
6. Grouped sales by category.
7. Grouped sales by region.
8. Filtered high-value sales.
9. Created bar charts using Matplotlib.
10. Exported analyzed data into CSV.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the program:

python analysis.py

## Conclusion
Successfully analyzed sales data using Pandas
and visualized the results using Matplotlib.
